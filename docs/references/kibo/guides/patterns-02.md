## Avatar

**Primitive and collection distinction.** Both collections use `Avatar`, `AvatarImage`, and `AvatarFallback` from the [mirrored avatar primitive](../upstream/packages/shadcn-ui/components/ui/avatar.tsx), which wraps Radix avatar primitives. Its default root and fallback are circular, `size-8`, and overflow-hidden. **`standard`** relies on those defaults. **`square`** changes the root and fallback to `rounded-lg`; all other markup and data are otherwise counterpart-for-counterpart identical. Image examples use the remote GitHub URL and fallback `HB`; that URL, handle, initials, count `3`, status color, and verification presentation are demo data, not a user model.

## Badge

The four collections below differ only by the `variant` prop (or default variant); each repeats five compositions.
