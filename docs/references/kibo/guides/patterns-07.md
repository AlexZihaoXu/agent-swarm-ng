## Architecture

All three families are standalone client-side TSX examples. Their `@/components/ui/*` imports are required application primitives, while each file’s hard-coded records, labels, and external example values are demo content. The snapshot is not a runnable dependency tree, so aliases and primitive implementations were not resolved or executed.
