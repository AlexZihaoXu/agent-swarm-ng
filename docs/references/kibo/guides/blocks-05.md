## Project fit boundary

The current application is a scaffold dashboard: it renders connection status and explicitly says container management and desktop streaming are unimplemented ([`frontend/src/app.tsx:20-47`](../../../../frontend/src/app.tsx)); README defines its initial scope as template-based environment lifecycle management ([`README.md:31-39`](../../../../README.md)). Thus none of these upstream marketing/portfolio/download defaults establishes an application requirement. If a block is later selected, integrate only product-approved copy/data/actions and adapt its `@repo/shadcn-ui` imports rather than treating the demo as drop-in application behavior.
